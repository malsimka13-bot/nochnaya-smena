# Ночная смена

Учебное веб-приложение кофейни, которая открыта с 16:00 до 04:00. Напитки названы командами терминала.

Возможности: каталог с поиском и фильтрами, корзина, регистрация и вход, оформление заказа, чек с QR-кодом статуса, стикеры на чеке (перетаскивание), блог «Напиток недели + что слушать», панель администратора со статистикой (графики и таблицы на SVG).

Стек: Python, FastAPI, SQLAlchemy, SQLite; фронтенд на чистом JavaScript без сборки.

Проверено: Arch Linux, Python 3.14 (запуск тестов). На Windows запуск не проверялся, инструкция ниже собрана по стандартным командам.

## Что нужно

- Python 3.14 (подойдут и более ранние 3.x, но проект проверялся на 3.14)
- Интернет только для установки пакетов. Сам сайт работает без интернета.

## Установка и запуск: Linux

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app
```

## Установка и запуск: Windows (PowerShell)

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app
```

Если PowerShell запрещает активацию, выполните один раз `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или используйте командную строку (cmd): `.venv\Scripts\activate.bat`.

## Открыть сайт

Адрес: <http://127.0.0.1:8000>. Документация API, которую строит FastAPI: <http://127.0.0.1:8000/docs>.

При первом запуске создаётся файл базы `nochnaya_smena.db` и заполняется демо-данными: 13 напитков, 3 записи блога и заказы за последние 90 дней (для графиков).

| Роль | Email | Пароль |
|---|---|---|
| Администратор | admin@smena.local | admin123 |
| Клиент | client@smena.local | client123 |

Пароли демо-аккаунтов учебные. Для настоящего запуска задайте свой `SECRET_KEY` и поменяйте пароли.

Чтобы начать с чистой базы, остановите сервер и удалите файл `nochnaya_smena.db`.

## Тесты

```bash
pytest -q
```

Тесты используют отдельную временную базу и не трогают рабочую.

## Проверка QR-кода с телефона

QR на чеке ведёт на страницу статуса заказа. По умолчанию адрес в QR равен `127.0.0.1`, поэтому телефон его не откроет. Чтобы проверить с телефона (компьютер и телефон в одной Wi-Fi сети):

1. Узнайте IP компьютера в локальной сети (например, `192.168.0.15`). Linux: `ip -4 addr`. Windows: `ipconfig`.
2. Запустите сервер так, чтобы он слушал сеть, и передайте публичный адрес.

Linux:
```bash
PUBLIC_URL=http://192.168.0.15:8000 uvicorn app.main:app --host 0.0.0.0
```

Windows (PowerShell):
```powershell
$env:PUBLIC_URL = "http://192.168.0.15:8000"
uvicorn app.main:app --host 0.0.0.0
```

3. Если страница не открывается, разрешите входящие подключения на порт 8000 в брандмауэре.

## Настройки (переменные окружения)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DATABASE_URL` | строка подключения SQLAlchemy | `sqlite:///./nochnaya_smena.db` |
| `SECRET_KEY` | ключ подписи токенов входа | учебный ключ в коде |
| `PUBLIC_URL` | адрес сайта, который попадает в QR | адрес, по которому открыт сайт |
| `SEED_DEMO` | `0` отключает демо-заказы при первом запуске | `1` |
| `PBKDF2_ITERATIONS` | число итераций хеширования паролей | 260000 |

## Правила, которые проверяют сервер и тесты

- Цена и сумма заказа считаются на сервере. Остатки списываются при заказе и возвращаются при отмене.
- В заказе не больше 20 позиций и не больше 20 штук одного напитка.
- Статусы заказа идут по цепочке: принят → готовится → готов → выдан. Отменить можно принятый и готовящийся заказ. Клиент отменяет только принятый.
- На чеке не больше 12 стикеров, координаты внутри чека, поворот не больше 45°.
- Ошибки в ответах API делятся на `input` (ошибка ввода), `auth` (нужен вход или нет прав) и `server` (сбой сервера). Сайт показывает их по-разному.

## Структура

```
app/            серверная часть
  main.py         маршруты API, обработка ошибок
  models.py       таблицы базы данных
  schemas.py      проверка входных данных
  services.py     правила заказов, статусы, статистика
  security.py     хеш паролей и токены
  seed.py         демо-данные
  catalog.py      меню, стикеры, примеры постов
static/         интерфейс
  index.html      основная страница (маршрутизация на хешах #/...)
  status.html     публичная страница статуса заказа (открывается по QR)
  css/style.css   оформление
  js/             модули интерфейса и графиков
tests/          автотесты
```

## Известные ограничения

- Токен входа хранится в `localStorage` браузера.
- Нет ограничения числа попыток входа и подтверждения email.
- Корзина хранится в браузере, поэтому у каждого устройства своя.
- Остатки напитков и демо-пароли подходят для учебного стенда, не для публикации в интернете.
